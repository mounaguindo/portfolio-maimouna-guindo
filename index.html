Projet — du code au cluster

Exercice mené dans le cadre du cours de Cloud Computing : développer une application, la conteneuriser, la versionner sur GitHub, comprendre son orchestration avec Kubernetes, puis l'héberger sur Render.

01

Développement

Application construite en PHP avec Laravel / Symfony.

02

Conteneurisation

Empaquetage de l'app dans une image Docker portable.

03

Versioning

Code source publié et suivi sur GitHub.

04

Orchestration

Notions de cluster Kubernetes : nodes, pods, services.

05

Hébergement

Déploiement continu de l'application sur Render.

concepts explorés
$ cluster

Ensemble de machines (nodes) qui travaillent ensemble pour exécuter une application de façon fiable.

$ node

Une machine, physique ou virtuelle, membre du cluster et hébergeant des pods.

$ pod

La plus petite unité déployable dans Kubernetes : un ou plusieurs conteneurs exécutés ensemble.

$ service

Point d'accès stable qui expose et équilibre le trafic vers un groupe de pods.

$ scaling

Ajustement automatique du nombre de pods selon la charge de l'application.

$ deploy

Publication continue d'une nouvelle version de l'application vers l'environnement hébergé.
